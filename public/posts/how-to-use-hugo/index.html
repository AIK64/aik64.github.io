前言#

Hugo 是一款使用 Go 语言编写的静态网站生成器，以构建速度快、部署简单著称。本文记录使用 Hugo 搭配 PaperMod 主题搭建个人博客的完整流程，方便日后查阅。

阅读本文前，请确保本地已安装 Git 与 Hugo。

一、创建 GitHub Page 仓库#

  1. 登录 GitHub，新建一个名为 <username>.github.io 的仓库（<username> 为你的 GitHub 用户名）。
  2. 该仓库将作为博客源码与静态页面的托管地址。

二、安装 Hugo#

1. 拉取仓库到本地#

git clone https://github.com/<username>/<username>.github.io.git

2. 创建新站点#

hugo new site MyFreshWebsite --format yaml

--format yaml 表示使用 YAML 格式生成配置文件（hugo.yaml）。

3. 安装 PaperMod 主题#

以 Git 子模块的方式引入主题：

git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod

# 重新克隆仓库时，子模块可能不会自动拉取，需执行以下命令
git submodule update --init --recursive

4. 启用主题#

在 hugo.yaml 中添加：

theme: ["PaperMod"]

三、使用 Hugo#

1. 使用命令创建新文章#

hugo new posts/my-first-post.md

Hugo 会在 content/posts/ 目录下生成带有默认 Front Matter 的 Markdown 文件。

2. 直接创建 Markdown 文件#

也可以手动在 content/posts/ 目录下新建 .md 文件，并在文件头部添加 Front Matter，例如：

---
title: "文章标题"
date: 2026-08-03T10:00:00+08:00
draft: false
tags: ["标签"]
categories: ["分类"]
---

draft: false 表示该文章为正式发布状态；设为 true 则为草稿，默认不会被构建。

四、本地调试与预览#

hugo server

启动后，默认访问地址为：http://localhost:1313/

常用参数：

参数说明
-D / --buildDrafts构建时包含草稿文章
--disableFastRender禁用快速渲染，确保页面完整刷新
-p <port>指定本地服务端口

示例：

hugo server -D --disableFastRender

五、构建与部署#

生成静态文件（默认输出到 public/ 目录）：

hugo

将构建产物推送到 GitHub 仓库后，即可通过 GitHub Pages 访问你的博客。
